# Guía para validar el prototipo

**Estado:** pendiente de realizar con participantes. No se reportan resultados de usuarios en este repositorio.

## Preparación

- Invitar de 5 a 8 personas adultas con distintos niveles de familiaridad con aplicaciones móviles. La participación es voluntaria.
- Usar datos ficticios; no pedir salario, CV real, teléfono, dirección ni otra información identificable.
- Pedir permiso antes de tomar notas. Registrar observaciones sin nombres.
- Facilitar un teléfono y, si se desea, una computadora; no explicar la ruta antes de cada tarea.

## Tareas

1. Desde el inicio, explica con tus palabras para qué sirve Mi Ahorro.
2. Prepara una lista para un hogar de cuatro personas con un presupuesto de $25.
3. Señala qué te permite saber si un precio es confiable y qué información falta.
4. Busca ejemplos de oportunidades relacionadas con dos habilidades tuyas.
5. Explica qué significa el porcentaje de coincidencia y si la tarjeta muestra una vacante activa.
6. Encuentra la herramienta para preparar una entrevista y describe qué pasa con el texto que escribes.

## Criterios para decidir ajustes

- La persona identifica que el producto organiza compras y también explora empleo.
- Puede crear la lista sin ayuda y entiende el saldo restante.
- Distingue datos de ejemplo de datos verificados.
- Interpreta el porcentaje de empleo como orientación, no como garantía.
- Encuentra el aviso de privacidad y entiende que no hay almacenamiento en esta demo.
- Se anotan fallos de teclado, foco, contraste, lectura en móvil y lenguaje confuso.

Priorizar problemas que impidan completar una tarea o que hagan pasar un ejemplo por dato real. Después de los cambios, repetir las tareas afectadas.
