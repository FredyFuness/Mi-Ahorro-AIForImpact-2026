# Alcance y límites de la demo

- Los precios del catálogo son cantidades ficticias para mostrar el flujo. No representan precios de comercios, no tienen fecha de consulta y no deben usarse para decidir una compra real.
- Los cargos y empresas de la sección de empleo son ejemplos no activos. El enlace de cada uno apunta a `example.com`, no a una vacante.
- La lista se distribuye con una regla aritmética simple por partes iguales del presupuesto. El tamaño del hogar se muestra y se calcula el monto por persona, pero no se estiman cantidades nutricionales. No considera marcas, ofertas, inventario, transporte ni necesidades médicas o culturales.
- La coincidencia de empleo cuenta palabras coincidentes y ubicación. No evalúa experiencia, requisitos legales, sesgos, idoneidad ni probabilidad de contratación.
- La asistencia de CV ofrece pautas fijas y preguntas genéricas. No usa un modelo generativo, no verifica la información y no guarda el texto como perfil.
- La API no tiene base de datos, autenticación, cuentas ni persistencia. El frontend conserva los valores solo en el estado de la sesión del navegador.
- No se han realizado pruebas con usuarios ni auditoría formal de accesibilidad. La guía de validación está pendiente.
- La demo no garantiza ahorro, vigencia de precios, legitimidad de ofertas ni contratación.

Antes de producción se deben obtener fuentes con permiso de uso, registrar comercio y fecha para precios, conservar la URL original y fecha de consulta de cada vacante, definir consentimiento y retención, verificar seguridad y accesibilidad, y validar recomendaciones con usuarios.
