## 🌎 El problema
El costo de la canasta básica y los gastos cotidianos dificultan la administración del presupuesto familiar. Además, encontrar oportunidades para generar ingresos puede ser complicado.

## 💡 Nuestra propuesta
**Mi Ahorro** es una propuesta de aplicación móvil orientada a:
- Planificar compras de productos básicos de acuerdo con un presupuesto.
- Consultar y comparar precios de referencia con fecha y lugar de origen.
- Sugerir listas de compras económicas mediante inteligencia artificial.
- Descubrir ofertas laborales relacionadas con habilidades e intereses.
- Apoyar la preparación de CV y entrevistas.

> **Estado actual:** propuesta de solución desarrollada para el Challenge #AIForImpact de NAUFest 2026. Las funcionalidades descritas son objetivos del producto; este repositorio no afirma que exista una aplicación funcional ni datos de precios u ofertas en tiempo real.

## 🧠 Uso previsto de IA
1. Sugerir listas de compras ajustadas al presupuesto.
2. Organizar información de precios y presentar alternativas.
3. Relacionar habilidades del usuario con ofertas laborales verificables.
4. Ofrecer orientación para currículums y entrevistas.

La IA asistirá en decisiones, sin garantizar ahorros, empleo ni exactitud de información desactualizada.

## 🧱 Arquitectura propuesta
- **Frontend:** React + TypeScript, con interfaz adaptable a móviles.
- **Backend:** FastAPI (Python).
- **Persistencia:** por definir tras validar necesidades de usuarios.
- **IA:** servicio de recomendaciones y asistencia, sujeto a validación de datos, privacidad y costos.

Estas tecnologías son una **propuesta para desarrollo futuro**, no una implementación existente.
